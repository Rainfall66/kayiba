    游戏规则

    系统随机选一名角色作为答案(超弦体或晶源体),你输入角色名,每次猜测会新增一行,逐属性给出反馈。

    反馈颜色

    • 绿色(命中) —— 阵营、定位、武器类型、性别、类型与答案相同
    • 黄色(接近) —— 年龄相差 3 岁以内、生日相差 15 天以内
    • 灰色 —— 与答案差距较大,或该属性为未知("-")
    • 箭头 —— 年龄提示目标更大/更小,生日提示更晚/更早(规则说明,棋盘上以箭头符号显示)

    属性说明

    • 阵营:欧泊 / 剪刀手 / 乌尔比诺 / 晶源体
    • 定位:决斗 / 控场 / 守护 / 支援 / 先锋
    • 武器类型:自动步枪 / 精确射手步枪 / 狙击步枪 / 微型冲锋枪 / 机枪 / 霰弹枪
    • 类型:超弦体 / 晶源体
    • 搜索:支持别名联想,如 爆裂魔怪(贝利亚)、刺镰魔怪(粉莓)、冥荆皇女(蓝莓)、血荆皇女(草莓)

    胜负

    角色名猜对即胜;5 次仍未猜中或主动查看答案则失败。
