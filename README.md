# 卡一把 · 卡拉彼丘角色猜测游戏(单机版)

> **非官方粉丝作品** —— 与创梦天地 / 《卡拉彼丘》官方无关。
> 猜角色类 Wordle 玩法:输入角色名,根据逐属性颜色反馈,5 次机会内猜出目标角色。

纯静态、零依赖、双击即玩:一个文件夹拷到任何电脑,浏览器打开 `index.html` 就能玩,无需 Node / 数据库 / 联网。

## 玩法

- 系统随机选一名角色作为答案(**超弦体 24 名 + 晶源体 5 名**);
- 输入角色名(带自动补全),每次猜测新增一行逐属性反馈;
- 🟩 **绿色(命中)** —— 阵营 / 定位 / 武器类型 / 性别 / 类型与答案相同
- 🟨 **黄色(接近)** —— 年龄相差 3 岁以内、生日相差 15 天以内(跨年按环形计算)
- ▲▼ **箭头** —— 年龄提示目标更大/更小;生日提示更晚/更早(**按自然年内排名**,非环形方向,如 1月1日 vs 12月25日:1月1日更早)
- ➖ **"-"** —— 未知属性(晶源体的年龄/定位/武器类型/生日暂无,对比按灰色处理)
- **搜索别名**:输入 贝利亚(爆裂魔怪)、粉莓(刺镰魔怪)、蓝莓(冥荆皇女)、草莓(血荆皇女)等也能联想
- **拼音联想**:输入**全拼或首字母**都能找到角色 —— `xinghui` / `xh` → 星绘,`mxe` → 米雪儿·李,`blmg` 或 `beiliya` → 爆裂魔怪;忽略大小写、空格、中点与连字符。⚠️ **拼音仅用于联想候选,不能直接提交**,需点选候选项后再提交(避免 `xin` 这类歧义输入误提交)
- 🖼 **图片** —— 输入框下拉候选与猜测行显示角色小头像;猜中/查看答案时在结算弹窗展示答案**立绘**(每个角色 1~3 张,开局随机选一张并固定,不会重渲染时换图)
- 5 次机会内猜中角色名即胜;战绩与最近目标保存在本机浏览器(localStorage)

## 自定义角色数据

编辑 `characters.js`,字段说明见文件头注释:

```js
{ nickname: "角色名", team: "阵营", role: "定位", weapon: "武器类型",
  gender: "性别", age: 年龄, birthday: "生日(四位字符串MMDD,一位数月份前补0:\"0105\"=1月5日、\"1010\"=10月10日;\"0\"=未录入)",
  crystal: "类型", alias: "搜索联想词",
  avatar: "images/xxx-avatar.png",                     // 小头像(可省略,省略则不显示)
  images: ["images/xxx-1.png", "images/xxx-2.png"],     // 立绘数组,游戏内随机取一张(可为空数组)
  pinyin: "quanpin", pinyinAbbr: "qp" }                 // 拼音联想用(仅联想,不可直接提交)
```

- 阵营:欧泊 / 剪刀手 / 乌尔比诺 / 晶源体
- 定位:决斗 / 控场 / 守护 / 支援 / 先锋(留空 = 未知,显示 "-")
- 武器类型:自动步枪 / 精确射手步枪 / 狙击步枪 / 微型冲锋枪 / 机枪 / 霰弹枪
- 类型:超弦体 / 晶源体

改完保存刷新即生效。

## 图片资源

- `images/` 共 **107 张 PNG**:29 张角色头像 + 78 张立绘(每角色 1~3 张,优先收录"初始"时装),均保留了透明通道;
- 文件名统一用 **ASCII 拼音 slug**(如 `xinghui-avatar.png`、`xinghui-1.png`),避免中文文件名在 zip 解压、URL 编码上的兼容问题;
- 体积参考:头像约 30~90 KB(200px),立绘约 60~150 KB(320px),整套约 9 MB;
- 想换图/加图:把图片放进 `images/`,在 `characters.js` 对应角色的 `avatar` / `images` 里填相对路径即可;图片加载失败会自动隐藏,不会出现破图。

## 文件结构

```
├── index.html      # 入口(开始页 / 游戏页 / 规则与结算弹窗)
├── app.js          # 全部逻辑:选目标 / 判定 / 补全 / 棋盘 / 图片 / 存档

├── images/         # 107 张图片(29 头像 + 78 立绘)

```

## 技术说明

- 纯原生 HTML/CSS/JavaScript,无框架、无构建、无外部依赖,支持 `file://` 直接打开;
- **移动端自适应**:与在线版一致的紧凑固定棋盘、底部输入坞(键盘弹起自动贴底)、安全区适配与大触控目标;
- 判定规则(年龄±3、生日环形±15 天、同属性绿、未知灰)与在线版(Node 服务端)保持一致;
- 在线版(支持存档/排行/管理后台的完整版)见同源项目,部署方式见 `docs/部署指南.md`。
